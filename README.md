# IOT_ADAS_CDAC
**IoT enabled ADAS using CAN**

* Developed firmware in Embedded C for microcontrollers, focusing on 
real-time data acquisition, processing, and message framing over CAN. 
* Designed and developed an embedded ADAS prototype integrating 
multiple sensors interfaced with STM32-F07 for real-time data 
exchange between electronic control units (ECUs). 
* Build using HAL also integrated UART, I2C, ADC, DAC, Timers, 
Interrupts, bare metal, PWM, etc. 
* Implemented CAN (Controller Area Network) for reliable, low-latency 
transmission of sensor data such as distance, speed, Fluid level and 
obstacle detection parameters. 
* Implemented IoT connectivity to transmit processed data to a cloud 
platform for remote monitoring, visualization, and analytics. 
* Demonstrated understanding of embedded systems, in-vehicle 
networking, and ADAS concepts aligned with industry standards.
